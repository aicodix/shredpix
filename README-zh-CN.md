# Shredpix 简体中文本地化（v1.22）

本分支为 Shredpix 官方 v1.22 添加简体中文（中国）界面资源，不修改图片传输算法或应用运行逻辑。

## 变更内容

- `app/src/main/res/values-zh-rCN/strings.xml`：新增简体中文字符串和数组资源。
- 英文默认资源与中文资源已逐项核对：字符串条目数量一致，未发现缺失、额外或重复的资源名称；相关数组条目数也一致。

## 验证

- Android debug APK 构建成功。
- 已安装到 Android 设备进行实际运行检查，中文界面显示正常。

## 说明

- 使用 Android 资源限定符 `values-zh-rCN`。
- 系统语言匹配简体中文（中国）时会使用本地化资源；其他语言会回退到默认资源。
